# english-speak (optional Vite version)

This is the **developer** React/Vite build of SpeakDay.

For normal use with **XAMPP**, ignore this folder and use:

```
../speakday/
```

Copy `speakday` into XAMPP `htdocs` and open `http://localhost/speakday/`.

See [`../speakday/README.md`](../speakday/README.md).
